mend applies AI-written edits in four formats — unified diffs (often with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files, finding each edit's lines at the first of three matching tiers and writing every change or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
